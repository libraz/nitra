# Framing and text

This page covers framing, destination crops, text, and typefaces.

## Framing

Framing covers flips, quarter turns, straightening, and a crop that can be locked to a shape. Straightening trims the frame to keep it filled, so no corner comes out empty.

## Destination crops

A crop can target what a destination actually publishes: Instagram, X, Facebook, YouTube or TikTok. The shape and the size are taken as one decision. The size is a ceiling and an export is never enlarged (see [Introduction](introduction.md)).

## Text

Text can be added to the picture. Type is rasterised by the browser, so Japanese composes correctly. It is composited after the output transform, because a caption is not light that was in the room (see [Grading](grading.md)).

## Typefaces

Text can be set in any typeface on the machine. Loading a font file adds it to the picker, with its sample set in the face itself. If the caption contains a character the face has no glyph for, the panel says so, rather than letting the substitution be discovered in the exported file.
