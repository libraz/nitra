# グリッド分割

このページでは、1 枚の写真をグリッド状の複数投稿に分割する機能と、タイルを投稿する順番を説明します。

## 投稿順

プロフィールのグリッドは新しい投稿から埋まります。最後に投稿したものが左上に来るので、9 分割した写真は右下のタイルから順に上げることになります。逆に上げてしまったことに気付くのは、投稿が公開されたあとです。

nitra はその順番を計算して、ファイル名の先頭に書き込みます。番号どおりに上げるだけで組み上がります。タイルは ZIP 1 つにまとめて書き出します。

## 分割のタイミング

切り分けるのは描画したあとです。1 枚の完成画像を切っているので、グレインも周辺光量も階調も、継ぎ目をまたいで一致します。タイルごとに描画すると、周辺光量が写真ではなくタイルの中心に掛かります。
