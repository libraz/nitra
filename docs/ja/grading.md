# 階調と色

このページでは、入力形式、色の扱い、階調の操作、効果、そしてすべての描画の最後にかかる出力変換を説明します。

## 対応形式

JPEG・PNG・WebP・AVIF・HEIC を開けます。HEIC をネイティブに読めるのは Safari だけなので、libheif をブラウザ内で使います。

## 色のパイプライン

すべてをリニア Display-P3 に変換し、中間バッファは 16bit/ch で通します。iPhone の写真は広色域で記録されていて、読み込み時に sRGB へ落とすとそこで失われます。

## 階調

露出、コントラスト、ハイライトとシャドウの復元、白レベルと黒レベル、ホワイトバランス、自然な彩度と彩度を調整できます。これらが作る階調の応答はトーンカーブとして表示します。

## 彩度

彩度は OkLch の chroma として伸縮し、肌の色相域ではゲインを減衰させます。HSV の saturation を定数倍すると色相が転び、肌がいちばん先に飽和します。

## 色別の調整

色別に、色相・彩度・輝度を動かせます。8 つの色域の中心は原色から算出していて、手で書き写してはいません。無彩色に近い画素には掛かりません。曇り空の色相は計算上の値にすぎないからです。

## 効果

スプリットトーン、チャンネル比率つきのモノクロ、フェード、周辺光量、グロー、シャープ、明瞭度、グレインがあります。

## 出力変換

描画の最後には、編集していない写真も含めて同じ出力変換がかかります。ハイライトはクリップせずなだらかに丸め、シーンの白を最大値の少し手前に置きます。そのあと 8bit へ落とす際にディザをかけます。

文字だけは、この変換のあとで合成します（[構図と文字](framing-and-text.md)を参照）。
