# 概要

nitra はブラウザだけで動く写真補正アプリです。このページでは、目的、プライバシーの扱い、編集内容の保持の仕方、扱わないことを説明します。

## nitra とは

スマートフォンの美顔カメラは、シャッターが開いている間に加工を掛けます。nitra は同じ種類の加工を後から、手元にある任意の写真に掛けます。モードを切り替え忘れた一枚も、他人に撮ってもらった一枚も対象です。

後追いで処理するので、フレームレートの制約がありません。重いパスを必要なだけ掛けられますし、値はいつでも戻せます。

## プライバシー

アプリは静的ファイルだけで構成されています。開いた写真はブラウザの中でデコードと描画をし、どこにも送りません。アップロード経路もアカウントもありません。タブを閉じれば編集は消え、手元に残るのは書き出したファイルです。

顔解析のモデルは、ページを開いた時点で他のホストから取得するのではなく、アプリ自身が配信します。ページを開いた時点で第三者へリクエストが飛べば、写真が端末から出なくても、アプリを使っていること自体をその第三者に伝えてしまうからです。モデルは URL とダイジェストの両方で固定しています。同じ URL の下でモデルが差し替わると、アプリが描くものが変わります。

## 編集の仕組み

元画像は変更しません。編集内容は JSON のレシピで、表示のたびにそこから描画しています。

レシピの量はすべて相対値です。半径は画像サイズに対する比率、座標は正規化した値、文字の大きさは枠に対する比率です。絶対ピクセルで持つと、同じレシピを別の写真に当てた瞬間に意味が変わり、バッチ適用やプリセット共有が後から入れられなくなります。文字が、4000px の書き出しでも 9 分割のタイル 1 枚でも同じ位置に収まるのも同じ理由です。

書き出しで引き伸ばすことはありません。投稿先から取った画素数は上限であって目標ではないので、それに届かない写真はそのままのサイズで書き出し、パネルにもその値を出します。プリセットに合わせるために画素を作ると、実際には持っていない解像度を名乗るファイルができます。

レシピは画素を含まず、写真と同じくブラウザの中だけにあります。レシピを保存・読み込みする操作はありません。

## 非目標

- **別人化しません。** 骨格の作り替え、顔の入れ替え、体型の改変、生成による描き足しは扱いません。背景の差し替えも同じです。写真が写っていない場所を名乗ることになり、同じ線の向こう側にあります。AI 編集のあとに顔を戻す機能は、同じ線を反対側から見たものです。戻すのはカメラが記録した画素だけです（[顔を戻す](restoring-a-face.md)を参照）。
- **サーバーを持ちません。** アップロード経路はなく、今後も作りません。
- **アカウント機能を持ちません。** 編集が残るのは書き出したファイルの中だけです。
- 動画は当面スコープ外です。パイプラインは後から拡張できる形にしてあります。

反射のぼかしの限界は [シミと映り込み](blemishes-and-reflections.md)に記載しています。
