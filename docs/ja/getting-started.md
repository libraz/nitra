# はじめかた

このページでは、公開デモの使い方と、手元での実行方法を説明します。

## デモを使う

[nitra.libraz.net](https://nitra.libraz.net) は機能を削った体験版ではなく、アプリそのものです。プライバシーの扱いも同じで、ページは静的ファイルだけ、開いた写真はブラウザの中でデコードと描画をします。インストールは要りません。

対応形式の写真を開きます（[階調と色](grading.md)を参照）。エディタにはモードが 2 つあります。かんたんモードは数値をいっさい出さず、選択肢を結果の画像で見せます。詳細モードは全パラメータを開きます（[画面と操作](interface.md)を参照）。書き出すと新しいファイルができます。開いた写真は変更されず、編集内容はタブを開いている間だけ存在します。

## 手元で動かす

デモはこのリポジトリと同じビルドを配信しています。手元で動かしたり開発したりする場合は次のとおりです。

```bash
bun install
bun run dev
```

`bun run dev` で `http://localhost:5173` に立ち上がります。初回は顔解析のモデルとそれを動かすランタイムを `public/models` に取得します。40MB ほどあり、ダイジェストで固定してあって、リポジトリには入れていません。なくてもアプリは動き、顔まわりの操作は解析が使えないことを表示します。

## 対応ブラウザ

WebGL2 と half-float のレンダーターゲットに対応したブラウザが必要です。Chrome・Edge・Safari・Firefox の最新版で動きます。

## コマンド

```bash
bun run check      # lint とフォーマット
bun run typecheck
bun run test
bun run build      # dist/ に静的ファイルを出力。どの静的ホスティングにも置けます
```
