# メタデータ

このページでは、書き出し時にメタデータをどう扱うかと、メタデータを残す・書き込むモードを説明します。

## 削除

顔写真はこれから SNS に上がる素材であることが多く、GPS タグに入った自宅の座標を一緒に持っていく必要はありません。削除が既定で、設定画面の奥ではなく最初の画面に出しています。書き出したバイト列に対してテストで検証しています。何も触っていない編集も同じ動作です。メタデータについて何も言っていないレシピは、メタデータのないファイルを書き出します。

| 項目 | 扱い |
| --- | --- |
| GPS 座標・標高・方位 | 削除 |
| 撮影日時・デジタル化日時 | 削除 |
| カメラとレンズの機種名 | 削除 |
| 本体シリアル番号 | 削除 |
| 埋め込みサムネイル | 削除 |
| 作者・著作権フィールド | 削除 |
| ICC 色プロファイル | **保持** — 除くと表示側で色が破綻します |
| Orientation | 画素に適用してから破棄 |

ブラウザの canvas エンコーダは EXIF を引き継がないので、この工程がなくても書き出しは結果的に綺麗です。それでも明示的に実行しているのは、いまの安全が副作用にすぎず、エンコーダを差し替えた日に、何も壊れないまま失われるからです。

## 引き継ぐ・書き込む

情報のほうが目的になることもあるので、残りの 2 つのモードを用意しています。**引き継ぐ**は元写真が持っていた値を書き戻します。**書き込む**は項目ごとに組み立てます。座標、撮影日時、カメラとレンズ、露出、撮影者と著作権表示です。座標は地図がクリップボードに置く形のまま貼り付けられます。2 つの欄に分けて打ち込む必要はありません。

どのモードでも、ファイルに入るのはパネルに並んでいる項目そのものです。元のメタデータはそれらの欄に読み込んだ時点で捨てていて、素通しはしません。そのため埋め込みサムネイルが書き出しに紛れ込むことがなく、見せていないタグがファイルに入ることもありません。削除は先に走るので、入っているものは入れると決めたものだけです。

## 符号化と形式

英数字以外の文字は、読み取り側が期待する 2 種類の符号化で書き込みます。メタデータを入れられるのは JPEG と PNG で、この版では WebP に入れられません。黙って落とすのではなく、その旨をパネルに出します。

**書き込む**状態の編集内容は座標を含むので、その状態で書き出したファイルには座標も入ります。これもパネルに書いてあります。
